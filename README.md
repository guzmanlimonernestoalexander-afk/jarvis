# Jarvis

Asistente personal por voz con Claude. Lo despiertas con un doble aplauso (o diciendo "Jarvis"), te escucha y te responde en voz alta. Es una app web que se instala en Android.

## Cómo usarla
1. Abre la página en Chrome en tu Android y elige "Instalar app".
2. Toca **Iniciar** y permite el micrófono.
3. En Ajustes pega tu clave de API de Anthropic (se guarda solo en tu teléfono).
4. Aplaude dos veces y habla.

## Qué hace
- Router de modelos: Haiku 5.5 para plática rápida, Sonnet 5.5 para explicaciones y fotos, Opus 5.5 para análisis a fondo.
- Memoria local: "Jarvis, acuérdate de que...".
- Cámara: "Jarvis, ¿qué ves?".
- Contador de gasto de la API.

La clave de API y la memoria nunca se suben a este repositorio: viven solo en el navegador del teléfono.
